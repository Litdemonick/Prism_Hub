# PrismHub — puente de actualización

Este repositorio existe **únicamente** para que versiones anteriores de la
app (que todavía preguntan en `Litdemonick/Prism_Hub` por costumbre) puedan
encontrar la actualización que les explica dónde seguir buscando de ahí en
más. No tiene código, y no va a tener releases nuevos después de este.

- El código de PrismHub es privado.
- Las descargas, notas de versión e Issues de ahora en más viven en
  **[Litdemonick/PrismHub](https://github.com/Litdemonick/PrismHub)**.
- El sitio oficial es **[litdemonick.github.io/PrismHub](https://litdemonick.github.io/PrismHub/)**.
